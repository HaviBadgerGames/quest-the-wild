# Quest The Wild 🌲

> SwiftUI app for iPhone 13 mini and Mac. Norse-themed outdoor quest tracker with dog mode, Pine Trail visuals, and Supabase sync.

---

## ⚡️ Try it instantly (no Xcode needed)

1. Clone the repo
```bash
git clone https://github.com/HaviBadgerGames/quest-the-wild.git
```

2. Open the `Preview/` folder
3. Double-click **`app-preview.html`** or **`onboarding-preview.html`** in your browser

No install. No setup. Just open the file.

---

## 📱 Try it in Xcode (iPhone + Mac)

1. Clone the repo
```bash
git clone https://github.com/HaviBadgerGames/quest-the-wild.git
```

2. Open Xcode → New Project → Multiplatform App
3. Drag all `.swift` files from `Sources/QuestTheWild/` into your project
4. Run on iPhone 13 mini simulator or Mac

---

## What it is
- Daily and weekly quests with XP and streaks
- Dog mode for hike logging
- Trail library
- Pine Trail colour theme (warm, earthy, readable)
- SwiftUI for iPhone and Mac
