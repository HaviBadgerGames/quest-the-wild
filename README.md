# Quest The Wild 🌲

> A real SwiftUI app for iPhone 13 mini and Mac. Norse-themed outdoor quest tracker with dog mode, Pine Trail visuals, and Supabase sync coming.

---

## Open in Xcode right now

```bash
git clone https://github.com/HaviBadgerGames/quest-the-wild.git
cd quest-the-wild
open Package.swift
```

That's it. Xcode opens the full app. Hit Run.

---

## What works
- Onboarding (4 steps, saves with UserDefaults)
- Home dashboard: XP, level bar, streak, quests done
- Quest list: daily / weekly / boss with Done button
- Dog mode: name, breed, toggle, hike log
- Trail library: distance, dog-friendly flag
- Settings with reset

---

## Supported
- iPhone 13 mini (iOS 17+)
- Mac (macOS 14+)

---

## Stack
- SwiftUI
- Swift 5.9
- Swift Package Manager (no CocoaPods, no extra setup)
- Pine Trail colour theme
- Supabase sync coming next
